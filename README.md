# 🌦️ Real-Time Weather App

A dynamic and interactive weather website that displays real-time weather information using a weather API. Built with a clean user interface, it allows users to explore current weather conditions from around the world.

## 🔧 Features

- 🌍 **Random City Weather on Refresh**  
  Each time the page reloads, it shows weather information for a randomly selected city.

- 🔎 **Search by City Name**  
  Users can enter any city name to view its real-time weather conditions including temperature, humidity, wind, and more.

- 🗺️ **Integrated Google Map**  
  Search and explore locations directly on the map with Google Maps integration.

- 🌤️ **Real-Time Data**  
  Weather information is fetched live using a public weather API (e.g., OpenWeatherMap).
  The api i used in this website is from Rapid - Api (free version)

## 🚀 Technologies Used

- HTML, CSS, JavaScript  
- Weather API (e.g., OpenWeatherMap)  
- Google Maps JavaScript API
